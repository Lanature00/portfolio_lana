01 — Le contexte

Le problème

Repérer manuellement chaque point lumineux sur un plan électrique est une tâche répétitive, surtout lorsque les symboles sont nombreux et de petite taille.

⊗⊗⊗⊗⊗⊗⊗⊗⊗⊗⊗⊗⊗⊗⊗⊗⊗⊗⊗⊗⊗

Un symbole de plafonnier mesure environ 14 pixels sur un plan.

03 — Le travail réalisé

De l'annotation à l'application

  1. 01

    Préparation des données

    112 ampoules annotées manuellement sur 7 plans électriques et 3 styles de dessin.

  2. 02

    Entraînement du modèle

    Entraînement d'un modèle RF-DETR Small avec Roboflow pour localiser les symboles d'ampoules.

  3. 03

    Développement de l'API

    Création d'une API FastAPI pour recevoir les images et retourner les coordonnées et scores de confiance.

  4. 04

    Interface et tests

    Développement d'une interface TypeScript interactive et de 22 tests automatiques avec pytest.

05 — Résultats

Les résultats

Des résultats encourageants, avec des limites identifiées.

112ampoules annotées
7plans dans le jeu de données
22tests automatiques
8–9/15ampoules détectées*
0faux positif observé*

* Mesuré sur un seul plan de test. Ce résultat illustre le comportement du modèle ; ce n'est pas une mesure de performance généralisable.

Limites
  • Le jeu de données reste limité à 7 plans.
  • Les symboles sont très petits, environ 14 pixels.
  • Certaines ampoules ne sont pas détectées.
  • Le modèle génère rarement de fausses détections sur le test réalisé, ce qui reste à confirmer sur d'autres plans.
06 — Perspectives

Et ensuite ?

  1. 01

    Enrichir les données

    Ajouter davantage de plans électriques pour améliorer la capacité de généralisation du modèle.

  2. 02

  3. 03

    Changer de domaine

    Adapter l'approche à d'autres plans techniques, notamment les plans de réseaux d'eau.
